# Duo Launcher

An iOS 26-style home screen for Android foldables that changes with the fold.

- **Folded:** app grid, "Search apps or ask Claude" bar, dock. Swipe up (or tap "All apps") for
  every app with search. Long-press an app to add/remove it from Home or the Dock, see app info,
  or uninstall.
- **Unfolded:** the home screen on the left half; on the right, a live panel: clock, Claude
  (message box, New chat, Claude Code), your next calendar events, latest notifications, and
  any widgets you add.
- **Half folded (tabletop):** big clock and what's playing on top; media controls and the dock
  on the bottom.

Typing in the ask bar filters apps; press enter to open an exact match or send the text to
Claude (the Claude app if installed, otherwise claude.ai).

## Install

Every push builds an APK. Open the repo's **Releases** page on your phone, download
`DuoLauncher.apk` from the newest "Duo Launcher build", and open it. Then tap
**Make Duo your home screen** (or Settings → Apps → Default apps → Home app).
Switch back to the Pixel launcher the same way.
